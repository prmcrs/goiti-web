# GOITI — estudio creativo

Landing responsive y hub de GOITI: estrategia, comunicación, fotografía, video, postproducción y contenidos para plataformas.

## Sitio

Cuando GitHub Pages esté habilitado, el sitio estará disponible en:

https://prmcrs.github.io/goiti-web/

## Desarrollo

Sitio estático sin dependencias: `index.html`, `assets/css/style.css` y `assets/js/main.js`. Para previsualizarlo, abrí `index.html` en el navegador o usá un servidor HTTP local. Los recursos tienen rutas relativas para funcionar bajo `/goiti-web/`.

## Publicación en GitHub Pages

Se incluye el workflow `.github/workflows/pages.yml`, que despliega el contenido desde la rama `main` en GitHub Pages. Para habilitarlo, entrá a **Settings → Pages → Build and deployment → Source → GitHub Actions**. Luego comprobá el despliegue en **Actions**.

## Información pendiente antes de anunciar el sitio

- Incorporar el logotipo oficial aprobado y fotografías o videos con permiso de uso.
- Confirmar número de WhatsApp, email y perfiles oficiales; los enlaces de contacto están intencionalmente deshabilitados hasta entonces.
- Reemplazar las tarjetas de portfolio de muestra por proyectos reales.
- Aprobar los packs comerciales y sus condiciones antes de ofrecerlos.

El contenido publicado es un *draft* de diseño, no una tienda ni un presupuesto comercial.
